# Research notes — vocabulary products & methods

## Products reviewed (strengths → Wortklar takeaway)

| Product | Strong ideas | Weak / cosmetic | Wortklar choice |
| --- | --- | --- | --- |
| **Anki** | Gold-standard SRS; FSRS/SM-2; full control | Harsh UX; setup burden; recognition-heavy decks | Transparent SM-2 + learning steps; typed production default |
| **Memrise** | Native-speaker exposure; memorable cues | Weaker scheduling transparency; video paywalls | Context via original example sentences, not cloned media |
| **Quizlet** | Fast study modes; easy sets | Weak long-term SRS in free tiers | Session structure over cramming modes |
| **Babbel / Busuu** | Guided dialogues; usage notes | Subscription; less SRS depth | Grammar after answer; no lock-in |
| **Drops** | Beautiful visuals; short sessions | Mostly recognition; limited production | Illustrations only when they teach (nouns/actions) |
| **Lingvist** | Adaptive gap-fill from frequency | Less bilingual RU support | Frequency-first lexicon + RU/EN modes |
| **Clozemaster** | Sentence context at scale | Overwhelming; noisy sentences | One curated example per lemma |
| **Duolingo** | Habit loops, streaks | Points/leagues distract; shallow vocab depth | Quiet streak + daily goal only |

## What actually improves retention

1. **Active recall / production** beats passive recognition for usable vocabulary.
2. **Spaced repetition** with failure-sensitive intervals beats massed practice.
3. **Contextual examples** improve form–meaning mapping and collocations.
4. **Article+noun binding** for German is non-negotiable for production skill.
5. **Manageable new-card intake** prevents review bankruptcy (≈10–20 new/day guideline; session default 30 total).

## Mostly engagement / cosmetic

- Leaderboards, gems, animated mascots
- Streak freezes and FOMO notifications
- Decorative badges without learning signal

Wortklar keeps a streak and daily goal as habit support, nothing more.

## Algorithm decision

FSRS generally schedules more efficiently than SM-2 when personal history is rich. Wortklar ships an **Anki-like SM-2 variant** with:

- short learning steps before graduation
- ease adjustments on hard/easy/again
- overdue-aware interval boost
- explicit “why this card” reasons in the session UI

This stays explainable without a parameter-fitting pipeline.
