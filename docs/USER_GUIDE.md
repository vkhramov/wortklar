# Wortklar — User guide

## Quick start

1. Install [Node.js 20+](https://nodejs.org/) if needed.
2. In this folder: `npm install`
3. `npm run dev` and open the printed local URL.
4. Choose a learning direction on the home screen.
5. Tap **Start session** and type answers; press **Enter** to check.

## Learning directions

| Mode | You see | You type |
| --- | --- | --- |
| English → German | English | German |
| Russian → German | Russian | German |
| German → English | German | English |
| German → Russian | German | Russian |

Only the languages for the selected mode appear during exercises. German solutions are hidden until you submit when you are translating *into* German.

## Answering nouns

Include the article: `der Tisch`, not only `Tisch`. Missing or wrong articles count as partially correct.

Umlaut helpers (`ä ö ü ß`) appear when producing German. `ae`/`oe`/`ue`/`ss` are also accepted as equivalents.

## Grades after feedback

- **Again** — show soon (learning step)
- **Hard** — shorter next interval
- **Good** — normal schedule
- **Easy** — longer interval
- **Already know** (new cards) — exclude from new intake; kept as known

## Daily goals & session size

Adjust in **Settings**. Default session size is 30 cards. Due reviews are never dropped just to protect the new-word budget.

## Backup

Settings → **Export backup** / **Import backup**. Progress is device-local only.

## Tips

- Prefer production modes (`→ German`) for speaking/writing skill.
- Keep new words modest if the review queue grows.
- Use topic/level filters when you want a focused week (e.g. transport + A1/A2).
