# Graded readers (A1–B1) for gap-fill fallback

Drop plain-text German reader exports here when Tatoeba has no match:

```
graded-readers/
  A1/*.txt
  A2/*.txt
  B1/*.txt
```

Prefer short classroom sentences. Encoding: UTF-8.

These files are gitignored (personal library). The build script prefers your files; if a level folder is empty it may seed a small public-domain snippet so the pipeline is not blocked.
